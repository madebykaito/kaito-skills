# Research: long, source-heavy projects

These skills are for long research projects built on many sources: a literature review, a project wiki of ingested sources, a manuscript, peer review. They come from research-superpowers and lean toward theology, biblical archaeology, ancient history and digital humanities. A quick web lookup or a one-off fact check needs no skill.

| Skill | Use when |
|---|---|
| `brainstorming-research` | Starting any research work: shaping the question, method and scope into an approved design doc. |
| `writing-research-plan` | Turning an approved design doc into a plan with a hypothesis, tasks and verification criteria. |
| `executing-research-plan` | Running a ready plan task by task, with subagents and a review per task. |
| `scaffold-research-project` | Creating a new research project folder from the template. |
| `literature-review` | A systematic literature search that ends in a graded source guide and BibTeX. |
| `acquire-sources` | Getting the PDFs for graded sources: open-access downloads plus a manual worklist. |
| `add-to-library` | Adding one PDF to the shared library with verified metadata, outside a project. |
| `ingest-source` | Reading one acquired source under a focus into a source page, entities and BibTeX. |
| `wiki-lint` | Checking the wiki's structure: frontmatter, broken links, orphans. Before drafting and finishing. |
| `semantic-wiki-review` | Auditing wiki content: contradictions, outdated claims, weak support. |
| `wiki-graph` | Mapping the wiki as a graph: hubs, bridges, gaps, exports. |
| `drift-report` | Checking the library, wiki and registered projects for drift. On demand only. |
| `drafting-manuscript` | Drafting a chapter, article or grant text from the wiki, one agreed section at a time. |
| `requesting-peer-review` | A two-stage review of a finished draft: constructive, then adversarial. |
| `grant-finder` | Finding German and European funding programs for a research topic. |
| `finishing-a-research-project` | The final checklist before submission, publication or archive. |

Overlap rule: `wiki-lint` is structure and is deterministic. `semantic-wiki-review` is content. `drift-report` composes the lint with library and cross-project checks.
