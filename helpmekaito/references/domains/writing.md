# Writing and copy

Marketing copy and prose. Interface text (buttons, errors, empty states) belongs to `better-writing` in [interface-rules.md](interface-rules.md).

| Skill | Use when | Not when |
|---|---|---|
| `copywriting` | Writing or rewriting marketing copy for a page: homepage, landing, pricing, feature, about. | The copy exists and only needs tightening: `copy-editing`. |
| `copy-editing` | Existing marketing copy needs review, polish or proofreading. | Nothing is written yet: `copywriting`. |
| `ogilvy` | The copy has to sell: positioning, headlines, promises, ads, long-form persuasion. | Neutral docs or UI text. |
| `stop-slop` | Any prose reads as AI-written and needs the tells removed. | The problem is the argument, not the phrasing. |

Pairs:
- New page copy: `copywriting`, then `stop-slop` as the last pass.
- A headline or positioning problem: `ogilvy` first, then `copywriting`.
- Copy for a specific page type: read [pages.md](pages.md) for the structure skill, which decides what copy is needed.
