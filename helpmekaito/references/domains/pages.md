# Page types

Each skill is the structure and art direction for one kind of page. Pick by what the page is for, then by audience.

| Skill | The page is |
|---|---|
| `landing-page` | A single-offer landing page for SaaS, an app or a service. The generic default. |
| `pricing-page` | A SaaS pricing page: plans, value metric, FAQs. |
| `product-proof-saas` | A SaaS or AI product page where a real workflow or demo is the proof. |
| `operational-enterprise-ai` | An enterprise AI, automation or security page for buyers who ask about approvals, audit and rollback. |
| `documentary-brutalist-agency` | An agency, studio or architecture site with billboard type and hard black-and-white chapters. |
| `editorial-portfolio-chapters` | A portfolio or creative-studio site where project work leads, in color-coded chapters. |
| `service-booking-flow` | An appointment-based service site: salons, clinics, spas, with a real booking flow. |

Overlap rules:
- `landing-page` gives structure and conversion logic. The other five give a full visual identity as well. For an AI product, prefer `product-proof-saas`. For an enterprise buyer, prefer `operational-enterprise-ai`.
- The two agency skills differ in tone: `documentary-brutalist-agency` is loud and monochrome, `editorial-portfolio-chapters` is dark, quiet and case-study led. If the user gave no tone, ask which.
- A page that exists and does not convert is `cro` in [seo-marketing.md](seo-marketing.md), not a rebuild.

These skills rarely run alone. See [recipes.md](../recipes.md) for the chains.
