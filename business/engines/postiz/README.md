# Postiz on this Mac

This optional Compose template runs Postiz and its data services; setup does not start it. Postiz is a separate AGPL service, not bundled code. Review the [upstream self-hosting instructions](https://github.com/gitroomhq/postiz-app) and pin tested image versions before production. Set `POSTIZ_JWT_SECRET`, `POSTIZ_DB_PASSWORD` and the OAuth client variables for the platforms you use in your shell or an untracked `.env` file. Use a URL-safe database password. Then run `docker compose -f business/engines/postiz/compose.yaml up -d`. Connect each channel in Postiz, make an API key, and save the key alone in a private file. Do not commit secrets. Restrict registration after the first account is created.

Set `POSTIZ_URL=http://127.0.0.1:4007/api` and `POSTIZ_KEY_FILE` to that file. For a remote server, set an HTTPS URL and grant consent with `kaito-engines.mjs consent postiz --owner <id> --grant`. Consent covers that URL's origin. Grant it again when the origin changes or when upgrading from consent recorded without an origin. See `social-publish/SKILL.md` for the approval and publishing flow. The compose template still needs verification against a live Postiz server.
