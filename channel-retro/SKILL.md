# Channel retro

Resolve the owner with `business` first. Pull the website interval with `kaito-umami.mjs`, then render the same seven-day interval with `kaito-channel-retro.mjs`. Read Instagram metrics from the insights snapshots. See `business/references/analytics.md` for commands and the fixture format. Do not infer missing metrics or sum unique visitors across periods. Label missing data, compare like-for-like intervals, and distinguish observations from hypotheses. Ask for the Instagram fixture when its insights data is not available.
